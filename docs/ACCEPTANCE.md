# 微信开发者工具验收

浏览器预览验证不替代以下原生验收。

1. 导入根目录，使用自己的 AppID 或游客模式，编译后应显示空状态。
2. 添加示例，看首页照片、苔绿按钮和底部导航。通过详情的三个页签切换内容。
3. 自建物品：填名称、选择分类、日期、价格；保存进入详情。重启模拟器，档案应保留。
4. 从首页记录故事：先选物品，保存后回首页；从档案记录则回原页面。测试纯文字、纯照片、图文及编辑删除。
5. 记录维修，金额留空／0／正数，检查累计；编辑金额后应同步变化。
6. 评价：标签多选、自定义、重新选择、补充文本；再次进入保留上次选择。
7. 离开：选择出售并填写金额，二次确认后回详情，在曾经拥有可找到，故事、维修、评价仍在。
8. 分类自建、上限设置为0或小于当前数量，确认仍可添加，只轻量提醒。
9. 拒绝照片权限、取消选择、存储容量不足时应有可理解反馈且不关闭未保存表单。
10. 真机：照片保存后重启微信检查、长文本、软键盘、底部安全区、返回时放弃确认。清除数据有丢失风险，测试前先备份。

发布前仍需：真实 AppID、对应主体与隐私配置、真机验证、平台审核；云同步及多设备恢复是后续开发项。
