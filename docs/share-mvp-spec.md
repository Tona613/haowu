# 好物分享 MVP 页面与交互规格

## 目标与范围

让用户从一件正在拥有的物品出发，完成「选择物品 → 编辑分享 → 预览 → 发布」，并在社区首页和帖子详情中看到已发布内容。当前版本先跑通单用户本地原型，不包含二手交易、私信、评论、关注、支付或真实多用户后端。

## 页面关系

```text
首页「分享好物」
  → 选择分享物品
  → 编辑分享
  → 帖子预览
  → 发布成功 / 帖子详情
  → 社区首页可见
```

各页面通过所选物品 ID 传递上下文。发布时将用户确认的帖子内容保存为独立帖子快照；此后物品档案或评价修改，不自动改写已发布帖子。

## 1. 选择分享物品

### 页面内容

- 标题：选择分享物品。
- 搜索框：按物品名称搜索正在拥有的物品。
- 默认快捷区：我的好物展台，展示当前展台物品；点卡片即可选择。
- 「从物品中选择」入口：打开底部分类选择浮层，使用一级、二级分类标签与物品列表。
- 分类、二级分类和数量读取与底部「物品」页相同的数据源；新增物品或分类后同步更新。

### 选择规则

- 只允许选择正在拥有的物品；已离开的物品不出现在展台快捷区、搜索结果或分类列表中。
- 展台只是快捷入口，不限制可分享范围；未放上展台的正在拥有物品仍可搜索或按分类找到。
- 分类过多时横向滑动；二级分类只显示当前一级分类下有正在拥有物品的分类。
- 搜索结果、展台卡片、分类列表最终都进入同一个编辑页，并传入物品 ID。
- 搜索无结果时显示明确空状态；展台为空时提示用户可搜索或从分类中选择，不阻断流程。

### 与「记录故事」选择流程的复用

复用搜索、分类浮层、正在拥有过滤、分类数据源同步、物品行样式和选择交互。分享选择页的默认内容改为「我的好物展台」，不展示「最近的故事」列表；故事快捷选物品只适用于记录故事。

## 2. 编辑分享

### 自动带入的物品信息

所选物品以摘要卡展示：照片、名称、分类、建档日期、实际相逢日期。

- 建档日期来自物品 `createdAt`。
- 实际相逢日期来自物品 `start`，即用户自述开始拥有它的日期。
- 两个日期默认公开，名称按用户确认的用语展示；清楚区分记录建档和实际相逢。
- 物品照片、名称和分类随所选档案带入。更换物品需返回选择页。

### 用户填写字段

| 字段 | 规则 | 初始呈现 |
| --- | --- | --- |
| 分享标题 | 必填；空值时不能进入预览 | 提示用户概括最想分享的一点 |
| 使用体验 | 必填；空值时不能进入预览 | 多行文本，鼓励写真实感受 |
| 补充照片 | 选填 | 可添加、删除、预览照片 |

### 评价关联

- 物品已有评价时显示「参考我的评价」入口；没有评价时不显示该入口。
- 入口可查看优点、缺点和「重新选择」记录，供用户自行组织正文。
- 评价内容不自动公开、不自动填入帖子，也不是发布条件。
- 用户自行写入正文并发布的部分属于帖子内容。

### 页面操作

- 返回：回到物品选择页，保留当前编辑内容（实现时通过页面状态或本地草稿暂存）。
- 下一步预览：标题、体验正文都填写后进入预览；缺项时在对应字段附近提示。

## 3. 帖子预览

按社区实际帖子卡片和详情的视觉结构展示最终公开内容，包括：

- 作者标识（当前本地原型显示「我」）。
- 物品照片、名称、分类。
- 建档日期、实际相逢日期。
- 分享标题、体验正文、补充照片。

预览中只展示最终帖子字段；评价原始数据不会因为用户点过「参考我的评价」而自动出现。页面底部提供「返回编辑」和「确认发布」。返回编辑时保留所有已填内容。

## 4. 发布与社区展示

- 点击「确认发布」后创建一条独立帖子记录，保存物品信息快照、标题、正文、补充照片、作者和发布时间。
- 防止按钮重复点击导致重复创建；成功后进入该帖详情。
- 已发布帖子出现在社区首页最新信息流中，点击可打开同一帖子详情。
- 本地原型使用现有本地数据存储；刷新后帖子仍可查看。
- 空社区状态或没有用户帖子时，已有社区示例内容继续作为示例展示；用户帖子置于最新内容位置。

## 5. 关键状态与校验

- 没有正在拥有的物品：选择页显示空状态；提示先创建物品。
- 展台为空：隐藏或呈现简洁空状态，但搜索及分类选择仍可用。
- 所选物品在编辑时已不存在或已离开：阻止继续发布，提示重新选择。
- 标题或体验正文为空：禁止进入预览，并定位到缺失字段。
- 图片添加失败：保留已输入文字，显示可理解的错误提示。
- 发布失败：不清空编辑内容，允许重试。

## 页面框架验收标准

1. 首页分享入口能进入选择页。
2. 展台物品、搜索结果和分类选择都只能选择正在拥有的物品。
3. 选择结果自动带出物品信息和两个日期，且日期公开状态符合默认规则。
4. 标题和体验正文均必填；补充照片选填。
5. 有评价时可查看并参考，但没有任何评价内容会被静默公开。
6. 预览内容与最终帖子一致；可返回编辑并保留内容。
7. 发布后进入帖子详情，帖子在社区最新信息流可见，刷新后仍存在。

## 2026-10-20 展示规则更新（覆盖上文日期展示约定）

分享编辑页将「实际相逢日期」改为「拥有时长」；预览、详情和社区卡片统一展示「分享时已拥有 N 天」。建档日期继续显示。物品档案的拥有开始日期保持不变，时长按原有陪伴天数算法计算（首日为一天），确认发布时固定保存。旧帖子按其发布日计算，不能随着当前日期增长。实际相逢日期不再直接展示在分享页面。
